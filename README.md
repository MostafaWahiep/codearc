# CodeArc

CodeArc is an interactive software engineering challenge platform.

## Repository structure

- `extension/` — VS Code extension
- `backend/` — backend services (planned)
- `challenges/` — challenge definitions and starter projects (planned)
- `runner/` — local challenge execution (planned)
- `shared/` — shared schemas and contracts (planned)

## VS Code extension

Install dependencies and build the extension from its directory:

```sh
cd extension
npm install
npm run compile
```

Open `extension/` in VS Code and press `F5` to launch the Extension Development Host.
